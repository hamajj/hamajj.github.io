# Portfolio Redesign Plan: Minimalist Terminal Aesthetic

## Project Overview
Complete UI/UX redesign of hamajj.github.io using Vue.js/Nuxt.js with Tailwind CSS and shadcn-vue components. Modern, minimalist, high-end terminal aesthetic.

### Core Aesthetic
- Premium "hacker's workstation" vibe
- Clean, monospace typography
- Subtle terminal prompts throughout
- Monochromatic base with strategic accent colors (red/cyan preserved)
- Refined micro-interactions

## New Features Detail

### Command Palette (⌘K)
- Press `⌘K` or `/` to open Spotlight-style command interface
- Commands:
  - `about` - Scroll to About section
  - `projects` - Scroll to Projects section
  - `contact` - Scroll to Contact section
  - `github` - Open GitHub activity section
  - `music` - Show Now Playing status
  - `clear` - Close palette
  - `help` - Show all commands
  - `sudo godmode` - Hidden: triggers Konami easter egg
- Global, triggered anywhere on the site

### Particle Canvas
- Interactive particle background responding to mouse movement
- Preserves and enhances existing BackgroundPipes concept
- Full-screen background layer
- Mouse movement creates ripple/disturbance effects

### Generative Header
- Procedural geometric art based on current time
- Changes subtly on each visit
- Hero background layer
- Creates unique visual identity per visit

## Spotify Integration Setup

### Developer App Creation
1. Navigate to: https://developer.spotify.com/dashboard
2. Log in with Spotify account
3. Click "Create App"
4. Fill in details:
   - App name: `Portfolio Now Playing`
   - App description: `Shows current Spotify track on personal portfolio`
   - Redirect URI: 
     - Development: `http://localhost:3000/api/spotify/callback`
     - Production: `https://hamajj.github.io/api/spotify/callback`
5. After creation, copy Client ID and Client Secret

### Environment Variables (.env)
```
SPOTIFY_CLIENT_ID=your_client_id_here
SPOTIFY_CLIENT_SECRET=your_client_secret_here
SPOTIFY_REFRESH_TOKEN=will_be_generated_after_oauth_flow
```

### OAuth Flow
- Server-side OAuth implementation
- Initial authorization generates refresh token
- Refresh token stored securely
- NowPlaying component fetches current track via server endpoint
